# Fonts

| `Caveat.ttf` | Caveat (variable, wght 400 to 700) | The Caveat Project Authors (Impallari Type) | SIL Open Font License 1.1 (`OFL-Caveat.txt`) | https://github.com/google/fonts/tree/main/ofl/caveat |

Used for the handwritten fridge note in the 3D world (src/world/visuals) and free for any other handwritten UI.
Load it with `new FontFace('Caveat', 'url(/fonts/Caveat.ttf)')` or `@font-face { font-family: Caveat; src: url(/fonts/Caveat.ttf); }`.
